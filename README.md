# Blog Tecnologia e Educação

Projeto desenvolvido para praticar HTML, CSS e JavaScript.

## Sobre o projeto

Este projeto apresenta posts sobre tecnologia e educação.

Foi adicionada uma imagem relacionada ao conteúdo dos posts para reforçar visualmente a mensagem apresentada.

## Recursos utilizados

- HTML
- CSS
- JavaScript
- GitHub Pages

## Imagem

A imagem utilizada representa a união entre educação e tecnologia.

Ela apresenta um livro aberto conectado a elementos digitais.

## Acessibilidade

A imagem possui o atributo `alt` com uma descrição relacionada ao conteúdo:

> Ilustração de um livro aberto conectado a elementos digitais, representando a união entre educação e tecnologia.

O texto alternativo ajuda pessoas que utilizam leitores de tela a compreenderem o significado da imagem.
